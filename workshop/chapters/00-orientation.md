# 00. 이번 실습에서 만들 것

이 장은 5분입니다.\
준비된 EC2의 VSCode Server에서 제주 여행 질문에 답하는 `JejuGuide`를 만듭니다.\
AgentCore CLI가 프로젝트 생성, 로컬 실행과 AWS 배포를 담당하고, Codex, Claude Code, Kiro CLI 중 선택한 하나가 코드를 작성합니다.

참가자는 시작 명령을 복사하고, 자신의 터미널에서 키를 입력한 뒤 **구현 프롬프트 하나와 배포 프롬프트 하나**를 전달합니다.\
00~02장의 프롬프트 카드는 설명이나 진단이 필요할 때만 사용합니다.

참가자마다 독립된 랩을 사용합니다.\
팀명을 정하거나 명령의 `team01`을 바꾸지 않습니다.\
`team01`과 `AtlasCliTeam01`은 모든 랩에서 사용하는 공통 실습 식별자입니다.

기본 경로에서는 별도 종합 검증을 생략하고 배포 상태와 예시 응답 한 번만 확인합니다.\
오류가 발생하거나 특정 기능을 바꾼 경우에만 해당 검사를 추가합니다.\
HUD 설치도 원하는 경우에만 진행하는 선택 사항입니다.

## 수업 전에 준비할 것

[사전 구성](../reference/preconfiguration.md)은 수업 시간 밖에서 완료합니다.\
전체 Git 소스, Node 24, Python 3.12, uv, AWS CLI, npm AgentCore CLI 0.28.1, Docker와 선택한 Agentic AI 코딩 어시스턴트의 설치 및 로그인을 준비합니다.

현재 EC2 역할의 배포 권한과 기존 CDK bootstrap도 진행자가 확인합니다.\
Docker는 사전 설치하되 이번 CodeZip 실습에서는 사용하지 않습니다.

교재 ZIP은 읽기용입니다.\
실행할 소스는 EC2의 `/home/ec2-user/my-project/jeju-atlas`에 있어야 합니다.

터미널 명령은 VSCode의 Bash에, 프롬프트는 선택한 Agentic AI 코딩 어시스턴트 대화창에 붙여넣습니다.\
Bedrock 단기 API 키는 Bash의 비공개 입력으로 받아 참가자 `.env`에 보관합니다.

## 100분 과정과 20분 여유

| 장 | 할 일 | 시간 |
|---|---|---:|
| 00 | 결과물과 진행 순서 확인 | 5분 |
| 01 | 시작 명령과 환경 활성화 | 10분 |
| 02 | 계정 범위와 Bedrock 키 준비 | 10분 |
| 03 | Agentic AI 코딩 어시스턴트로 검색 도구 구현 | 30분 |
| 04 | 배포, 결과 응답과 자원 인계 | 45분 |
| 핵심 과정 | 00~04장 | 100분 |
| 여유 | 배포 대기와 오류 확인, 결과 정리 | 20분 |
| 최대 | 설치 시간을 제외한 수업 | 120분 |

05~14장은 100~120분에 포함하지 않는 선택 과정입니다.\
전체 지도 웹, 컨테이너, 경로 엔진과 외부 데이터 연동은 핵심 과정 뒤에 진행합니다.\
HUD도 시간 밖에서 원하는 사람만 준비합니다.

## 보여줄 결과

“제주 해변 두 곳과 자료의 출처를 알려줘”라는 질문에, 검색 도구가 반환한 장소를 바탕으로 한국어 답변이 완성되는지 확인합니다.\
제공된 137개 장소는 실습용 시드입니다.\
공식 검증 자료로 소개하거나 없는 영업시간, 사진, 전화번호를 채우지 않습니다.

완료할 때는 참가자 프로젝트, 변경 파일, 본인 Runtime의 상태, 실제 원격 응답과 자원 정리 담당자를 보여줍니다.\
Runtime이 READY여도 응답이 실패했다면 원격 검증은 미완료입니다.\
기록은 `$ATLAS_CLI_PARENT/RESULTS.md`에 남기고 비밀값은 넣지 않습니다.
