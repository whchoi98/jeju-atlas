# 00. 이번 실습에서 만들 것

5분 동안 결과물과 진행 순서를 확인합니다.
준비된 EC2의 VSCode Server를 열고 선택한 AI CLI와 AgentCore CLI로
제주 여행 질문에 답하는 에이전트를 만듭니다.

AI CLI가 응답하더라도 실습 소스와 언어 도구까지 준비된 것은 아닙니다.
01장의 사전검사를 통과해야 다음 장으로 진행합니다.
PC의 교재 ZIP과 EC2에서 실행할 전체 Git 소스는 별도로 준비합니다.

AI CLI는 코드 작성과 오류 수정에 사용합니다.
AgentCore CLI는 프로젝트 생성, 로컬 실행, AWS 배포와 호출에 사용합니다.
참가자는 Codex, Kiro CLI, Claude Code 중 하나를 선택합니다.

터미널 명령은 VSCode의 **별도 Bash 터미널**에, AI 프롬프트 카드는 선택한
CLI의 대화창에 붙여넣습니다. 이미 다른 프로젝트를 처리 중인 Claude 세션에
실습 명령을 전달하지 않습니다. 실습 폴더에서 새 Claude 세션을 여는 절차는
[도구별 안내](../reference/ai-cli-environments.md)에 있습니다.

## 결과물

참가자마다 `JejuGuide`라는 에이전트를 만듭니다.
프로젝트 이름은 참가자별로 다르게 정하므로 다른 사람의 Runtime과 겹치지 않습니다.
에이전트는 Strands와 Bedrock 모델을 사용하고 제주 장소 JSON을 읽는 도구를 호출합니다.

예를 들어 “제주 해변 두 곳을 찾아주고 자료의 출처를 알려줘”라고 질문합니다.
도구가 반환한 장소 이름으로 답하고, 확인하지 않은 영업시간이나 편의 정보는 만들지 않아야 합니다.
이번에 사용하는 137개 장소 파일은 실습용 시드입니다. 공식 검증된 방문 안내로 설명하지 않습니다.

## 시간 배분

| 단계 | 시간 |
|---|---:|
| 결과물 확인 | 5분 |
| 준비된 도구 확인 | 10분 |
| 계정과 작업 위치 확인 | 10분 |
| AI CLI로 코드 구현 | 35분 |
| 로컬 실행, 배포와 원격 호출 | 50분 |
| 지연 대응과 결과 정리 | 10분 |
| 합계 | 120분 |

본 실습은 04장에서 끝납니다. 05장 이후는 선택한 사람만 이어서 진행합니다.
3D 지도, Fargate, Valhalla, CloudFront 기본 HTTPS와 공공 데이터 수집은 심화 과정에서 다룹니다.
기본 Runtime에 심화 과정의 Gateway나 Memory가 연결되어 있다고 가정하지 않습니다.

## 완료 확인

수업이 끝나면 다음 결과를 직접 보여줄 수 있어야 합니다.

1. AgentCore CLI가 생성한 프로젝트와 AI CLI가 수정한 파일
2. 제주 장소 검색 도구의 로컬 테스트 결과
3. 참가자 소유 Runtime의 배포 상태
4. 실제 모델이 장소 도구를 사용해 완성한 응답
5. 정리한 자원 또는 남겨 둔 자원의 이름

Runtime이 READY여도 모델 응답이 실패했다면 원격 호출은 미완료입니다.
로컬 테스트만 통과한 상태도 AWS 배포 완료로 기록하지 않습니다.
