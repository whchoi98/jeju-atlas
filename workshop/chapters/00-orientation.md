# 00. 이번 실습에서 만들 것

이 장은 실습 목표와 진행 순서를 확인하는 5분짜리 안내입니다.\
제주 여행 질문에 답하는 `JejuGuide`를 구현하고 AWS에 배포합니다.

| 도구 | 실습에서 맡는 일 |
|---|---|
| AgentCore CLI | 프로젝트 생성, 패키징과 AWS 배포 |
| Agentic AI 코딩 어시스턴트 | Codex, Claude Code, Kiro CLI 중 하나로 검색 도구 구현 |

참가자는 EC2의 VSCode Server에서 키를 입력한 뒤 **구현 프롬프트 하나와 배포 프롬프트 하나**를 전달합니다.\
00~02장의 프롬프트 카드는 설명이나 문제 해결이 필요할 때만 사용합니다.

## 하단 프롬프트로 진행하는 방법

**사전 구성과 01장의 키 입력을 마쳤다면, 03~08장은 하단 프롬프트를 한 장씩 실행하는 방식으로 진행하도록 작성돼 있습니다.**\
02장에서 계정과 작업 범위를 확인한 뒤 선택한 Agentic AI 코딩 어시스턴트에 해당 장의 카드를 전달합니다.\
**본문 명령과 프롬프트를 모두 중복 실행할 필요는 없습니다.**

프롬프트로 진행하면 코딩 어시스턴트가 본문의 명령과 코드를 읽고 해당 장의 작업을 수행합니다.\
직접 터미널에서 진행하려면 본문 명령을 순서대로 실행하고, 필요한 경우에만 프롬프트로 도움을 받습니다.

이미 일부 작업을 마쳤다면 다음과 같이 요청합니다.

> 이미 완료한 작업은 유지하고, 이 장의 남은 단계만 실행해 주세요.

도구 로그인, 숨김 API 키 입력, `newgrp docker`로 새 셸을 여는 작업은 사용자 터미널에서 수행합니다.\
도구가 승인을 요청하거나 오류가 발생하면 해당 단계의 결과를 확인하고 이어 갑니다.\
프롬프트를 전달한 것만으로 완료를 판단하지 않고 각 장의 완료 출력과 실행 결과를 확인합니다.

03~04장은 100~120분 본 실습의 구현과 배포이며, 05~08장은 추가 시간이 필요한 선택 심화 과정입니다.\
00~08장 명령어를 따라 진행한 참가자의 확인 결과와, 프롬프트만으로 연속 실행하는 전체 리허설은 구분합니다.

## 준비 상태에 맞는 다음 단계

| 현재 상태 | 이동할 곳 |
|---|---|
| 처음 시작하거나 EC2의 소스, 도구 설치와 점검이 남아 있습니다. | **[사전 구성: EC2 준비하기](../reference/preconfiguration.md)** |
| 사전 구성의 도구, AWS 자격증명과 CDK 배포 기반 준비를 마쳤습니다. | **[01. 환경 활성화와 Bedrock 키 입력](01-setup.md)** |

흐름은 **00장 개요 확인 → 필요한 경우 사전 구성 → 01장 활성화와 키 입력**입니다.\
사전 구성은 수업 시간 밖에서 완료하며, 준비를 마치면 바로 01장으로 이동합니다.\
설치 명령과 도구 버전 기준은 사전 구성 페이지에서 확인합니다.

## 100분 과정과 20분 여유

| 장 | 할 일 | 시간 |
|---|---|---:|
| 00 | 결과물과 진행 순서 확인 | 5분 |
| 01 | 환경 활성화와 Bedrock 키 입력 | 10분 |
| 02 | [계정과 작업 폴더](02-aws-environment.md) | 10분 |
| 03 | Agentic AI 코딩 어시스턴트로 검색 도구 구현 | 30분 |
| 04 | 배포, 예시 응답과 자원 인계 | 45분 |
| 핵심 과정 | 00~04장 | 100분 |
| 여유 | 배포 대기와 오류 확인, 결과 정리 | 20분 |
| 최대 | 설치 시간을 제외한 수업 | 120분 |

기본 과정은 배포 상태와 예시 응답 한 번까지 확인합니다.\
추가 검사는 오류가 발생하거나 특정 기능을 바꾼 경우에만 진행합니다.\
05~14장의 전체 지도 웹과 외부 연동, HUD는 핵심 시간 밖의 선택 과정입니다.

## 완료할 때 보여줄 결과

“제주 해변 두 곳과 자료의 출처를 알려줘”라는 질문에 검색 도구의 결과를 바탕으로 한국어 답변이 완성되어야 합니다.

- 참가자 프로젝트와 구현한 검색 도구
- 배포한 Runtime의 상태와 실제 원격 응답 한 번
- 결과 기록과 남은 자원의 정리 담당자

제공된 137개 장소는 실습용 시드입니다.\
없는 영업시간, 사진, 전화번호를 채우거나 공식 검증 자료로 소개하지 않습니다.\
Runtime이 READY여도 응답이 실패했다면 실제 응답 확인은 미완료입니다.

선택 프롬프트: [실습 목표 확인](../prompts/00-orientation.md)
