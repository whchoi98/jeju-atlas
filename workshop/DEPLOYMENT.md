# 워크숍 공개 배포 기록

2026-09-12에 120분 교재와 본문 화면 개선을 운영 워크숍 경로에 배포했습니다.

## 반영 내용

- 본 실습 5개 장은 110분이며 여유 10분을 더해 120분으로 편성했습니다.
- 나머지 9개 장은 선택하는 심화 과정으로 표시합니다.
- 1366px 화면의 본문 폭은 기존 760px에서 약 1020px로 넓어졌습니다.
- 1920px 화면의 본문 폭은 1268px입니다.
- 노트북 화면에서는 페이지 목차를 본문 위에 접힌 형태로 표시합니다.
- 셸 명령은 맥북 터미널 형태의 창으로 표시합니다.
- AI 프롬프트는 Codex, Kiro CLI, Claude Code 선택에 따라 이름과 색상을 구분합니다.
- 명령은 터미널로, 프롬프트는 선택한 AI CLI의 대화 입력창으로 복사하도록 표시합니다.
- 복사 내용에는 창 장식이나 교재의 부연 설명이 포함되지 않습니다.
