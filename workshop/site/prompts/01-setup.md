# 01. 준비된 도구 확인

설치 작업 대신 현재 환경을 확인합니다.

```text
준비된 EC2의 VSCode Server 터미널에서 도구를 점검해 주세요.
선택한 AI CLI, Node 24, Python 3.14, uv, AWS CLI와 AgentCore CLI 0.28.1의
실행 경로와 버전을 확인합니다. 로그인 파일이나 비밀값은 읽지 마세요.

VPC, NAT Gateway, Subnet과 세 AI CLI는 사전 설치되어 있습니다.
도구를 재설치하거나 전역 버전과 인증을 바꾸지 마세요.
누락된 항목은 현재 값과 필요한 조치만 알려 주세요.
AWS 자원 생성과 모델 호출은 이 단계에 포함하지 않습니다.
```
