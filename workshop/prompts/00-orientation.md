# 00. 실습 목표 확인

설명이 필요할 때만 사용하는 선택 카드입니다.\
필수 입력은 03장과 04장 카드 두 개입니다.

```ai-prompt
제주 가이드를 만드는 워크숍의 목표를 짧게 설명해 주세요.
핵심 과정은 00~04장 100분이며 여유 20분을 포함해 최대 120분입니다.
장별 시간은 5분, 10분, 10분, 30분, 45분입니다.
도구 설치와 로그인, EC2 배포 권한과 CDK bootstrap 준비는 수업 전에 끝냅니다.
05~14장, 외부 연동과 HUD는 핵심 시간 밖의 선택 과정입니다.

참가자는 현재 EC2의 VSCode Server에서 Codex, Claude Code, Kiro CLI 중 하나를 사용합니다.
AgentCore CLI 0.28.1로 Python 3.12 CodeZip 프로젝트를 만들고,
Agentic AI 코딩 어시스턴트가 제주 장소 검색 도구를 구현합니다.
각 참가자는 별도의 랩을 사용하므로 새 설정에는 공통 내부 ID team01과
프로젝트 AtlasCliTeam01을 사용합니다. 팀명을 배정하거나 바꾸도록 요청하지 마세요.
기존 작업의 이름과 설정은 그대로 유지합니다.
137개 장소는 실습용 시드이며 공식 검증 자료로 소개하지 않습니다.
없는 영업시간, 전화번호나 사진을 만들어 넣지 않습니다.

참가자는 Bash의 시작 블록과 비공개 .env 입력을 마친 뒤
구현 프롬프트 하나, 배포 및 예제 응답 프롬프트 하나를 전달합니다.
터미널 실행은 올바른 cd로 시작합니다. 새 셸에서는 저장소로 이동하고
기존 activate.sh를 source한 뒤 실제 작업 폴더로 다시 이동합니다.
Bedrock 단기 키는 모델 호출용이고 AWS 배포에는 현재 EC2 역할의 IAM 권한이 필요합니다.
카카오와 관광공사 등의 키는 첫 배포 뒤 필요한 것만 추가할 수 있습니다.
키를 대화창으로 보내거나 .env 내용을 보여 달라고 하지 마세요.

기본 흐름은 구현, 경로, 계정, 스키마 확인, 배포 계획과 적용,
Runtime 상태 확인 1회, 실제 도구를 사용한 최종 예제 응답 1회입니다.
별도 모델 사전 호출, 로컬 서버 점검과 전체 테스트는 기본으로 생략합니다.
실제 오류, 위험한 기능 변경 또는 사용자의 명시적 요청이 있을 때만
해당 부분을 좁혀 확인합니다. 생략한 검사를 통과로 표시하지 마세요.
HUD는 참가자가 선택했을 때만 설치하거나 실행합니다.

완료 기준은 참가자 Runtime 상태, 실제 검색 도구를 사용한 완성된 원격 응답,
그리고 남은 자원의 정리 담당자입니다. 배포 상태와 실제 응답 성공을 구분해 주세요.
이 카드는 목표 설명만 요청합니다. 설치, 코드 변경, AWS 배포와 모델 호출은 실행하지 마세요.
```
