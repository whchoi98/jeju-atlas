# 교통 혼잡도·선호·추천 연동 검토

2026-09-12 현재 코드, 공식 문서와 실제 API 호출을 확인했습니다.
이번 작업은 연동 가능성 검토이며 운영 화면을 변경하거나 배포하지 않았습니다.

## 확인 결과

| 항목 | 현재 상태 | 추가할 수 있는 기능 |
| --- | --- | --- |
| 도로 교통 | 기존 Atlas 카카오 키로 자동차 길찾기 조회 성공 | 선택 경로의 교통 상태·속도·예상 이동 시간과 조회 시각 |
| 대중의 선호 | 현재 장소 API에 별점·추천 수 없음 | 검증된 공식 인기 자료 또는 앱 이용자의 실제 찜·추천 집계 |
| 개인 맞춤 추천 | 전용 AgentCore Memory에 개인 선호를 저장·검색하는 구조 존재 | 동행·이동수단·관심 장소와 확인된 이용 정보를 반영한 추천 및 선정 이유 |

카카오모빌리티 `v1/directions`를 제주 시내 좌표로 한 번 호출했습니다.
HTTP 200과 경로 결과 코드 0을 받았고, 도로 구간 8개에 `traffic_state`, `traffic_speed`, `vertexes` 필드가 있었습니다.
당시 반환 경로는 4,279m, 예상 시간은 824초였습니다. 이는 확인 당시 한 경로의 응답입니다.
키는 기존 전용 SSM 파라미터에서 메모리로 읽었으며 기록·출력하지 않았습니다.

공식 교통 상태 코드는 0 정보 없음, 1 정체, 2 지체, 3 서행, 4 원활, 6 사고로 통행 불가입니다.
실제 응답에는 정보 없음도 포함됐습니다. 이런 구간을 원활한 것으로 표시하면 안 됩니다.
길찾기 응답의 교통 정보는 조회한 경로에 해당하며 제주 전체 도로의 완전한 혼잡 지도는 아닙니다.

현재 앱의 Valhalla 경로 응답은 `traffic: not_live`입니다.
교통 정보를 추가할 때는 카카오에서 반환한 경로·시간·구간을 함께 사용하고,
다른 경로 엔진의 선형 위에 그대로 혼잡 색상이나 시간을 붙이지 않습니다.

## 화면 구성안

- 이동 경로: **교통 상태 확인**, 도로 구간별 상태 색상, 현재 교통을 반영한 참고 시간, 조회 시각·출처.
- 장소 목록: **인기순**과 **나에게 맞춤**을 구분하고 점수의 근거를 표시.
- 장소 상세: 인기 집계의 출처·기간·건수, 개인 맞춤 추천 이유, 확인된 편의 정보.
- AI 가이드: 같은 교통·선호 데이터를 근거로 답변하고 확인되지 않은 값을 채우지 않음.

대중의 선호는 아직 데이터 소스 선택과 집계 기준이 필요합니다.
공식 인기 통계, 앱 내 찜·추천, 별점은 서로 다른 지표이므로 하나의 평점처럼 합치지 않습니다.
집계가 없는 장소에는 근거 없이 별점이나 인기 순위를 만들지 않습니다.

카카오 Local 공식 응답 항목과 비짓제주가 2026년 6월 게시한 7쪽짜리 API 활용 가이드를 확인했습니다.
기본 장소·위치·연락처·태그·이미지 항목은 있으나 별점·리뷰 수·추천 수·인기 정렬 항목은 확인되지 않았습니다.
추가 공개 인기 데이터는 해당 데이터셋의 제공 범위, 집계 기간과 사용 권한을 확인한 뒤 연결해야 합니다.
