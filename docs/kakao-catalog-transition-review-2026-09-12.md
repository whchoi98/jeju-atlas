# 카카오 중심 장소 탐색 전환 검토

이 검토 이후 권장 구성을 구현·배포했습니다.
현재 동작과 운영 검증은 [배포 기록](kakao-discovery-release-2026-09-12.md)을 참조합니다.

2026-09-12 공식 문서와 실제 카테고리 조회를 확인했습니다.
기존 6,724건의 카탈로그를 변경하거나 운영 화면에 전환을 배포하지 않았습니다.

## 현재 연결 누락의 구조

현재 탐색 목록은 OSM·시드 카탈로그에서 가져오고, 상세 화면을 열 때 카카오에서 같은 장소를 찾습니다.
앞선 이름·분류 매칭 수정은 이 후속 조회를 보완한 것이며 장소 목록의 원본을 교체한 작업은 아닙니다.
원본 간 이름·위치·등록 시점 차이가 있거나 카카오 검색에 결과가 없으면 연결을 확정할 수 없습니다.

카카오에서 받은 장소를 목록의 원본으로 사용하면 카카오 ID·분류·상세 URL을 함께 사용할 수 있습니다.
기존 카탈로그 이름을 카카오에서 다시 찾는 단계를 줄이는 전환입니다.

## 실제 확인

기존 Atlas 전용 키로 협재해수욕장 주변 2km를 두 번 조회했습니다.
각 요청은 예시 3건만 받았고 전체 수집을 시도하지 않았습니다.

| 카카오 분류 | 검색 결과 수(`total_count`) | 조회 가능 결과 수(`pageable_count`) |
| --- | --- | --- |
| 음식점 `FD6` | 179 | 45 |
| 카페 `CE7` | 62 | 45 |

음식점에서는 `음식점 > 분식`, `음식점 > 한식 > 육류,고기`, `음식점 > 치킨 > BHC치킨`,
카페에서는 `음식점 > 카페`, `음식점 > 카페 > 커피전문점 > 스타벅스` 같은 세부 분류를 반환했습니다.
모든 예시에 카카오 장소 ID와 해당 ID의 상세 링크가 포함됐습니다.
검색 결과 수는 당시 지정 범위의 API 응답이며 제주 전체 장소 수가 아닙니다.

## 권장 전환 범위

- 음식점·카페·숙박·주차장: 카카오 분류(`FD6`, `CE7`, `AD5`, `PK6`)로 현재 지도나 주변을 조회.
- 일반 관광명소·문화시설: 카카오 분류를 활용하되 기존 서비스의 세부 분류와 구분.
- 오름·해변·올레길: 카카오의 큰 분류 코드와 일대일로 대응하지 않으므로 관광 공공정보와 실제 코스 자료를 함께 사용.
- 사진·운영시간·편의 정보: 기존 TourAPI·VisitJeju의 검증된 보강 근거를 유지.
- 화면의 고정 `6,724곳` 표시는 카카오 조회 결과에 적용하지 않고 검색 범위와 반환 한계를 표시.

기존 사진·공식 상세, 저장한 여행·즐겨찾기·공유 링크는 현재 장소 ID와 연결됩니다.
기존 데이터를 삭제하지 않고 카카오 ID를 별도 식별자로 추가하는 전환 설계가 필요합니다.
확실하지 않은 이름 유사도만으로 저장 코스의 장소를 자동 치환하지 않습니다.

## 전체 DB 교체와 실시간 조회의 차이

카카오 Local은 키워드·카테고리·지역 범위로 검색하는 API이며, 제주 전체의 완전한 DB를 내려받는 기능이 아닙니다.
조회 결과를 모아 기존 6,724건과 같은 수량의 완전한 데이터셋을 만들 수 있다고 보장할 수 없습니다.

확인한 운영정책은 사용자 환경 개선 목적의 캐시와 최신 유지 조건을 규정합니다.
이용약관에는 사전 승낙 없는 복사·복제·검색 엔진 또는 디렉터리 입력 등에 관한 제한도 있습니다.
따라서 대량 수집 결과를 별도 장소 DB로 영구 저장해 교체하는 범위는 카카오의 사용 승인·계약 조건을 확인해야 합니다.
앱의 실제 사용자 조회에 응답하는 방식과 대량 DB 복제는 같은 것으로 전제하지 않습니다.

또한 카카오 Local의 기본 응답에는 사진·영업시간·별점·리뷰 수가 없습니다.
목록 원본을 카카오로 바꾸더라도 이러한 항목이 자동으로 채워지는 것은 아닙니다.
