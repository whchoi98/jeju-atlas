# 장소 목록 공간과 사진 없는 상세보기

## 변경 내용

상단의 검색 출처·필터·범위 설정과 카카오 안내가 결과 목록의 높이를 차지해,
노트북과 작은 휴대폰에서는 장소 카드 한 개도 온전히 보이지 않는 경우를 재현했다.

- 모든 화면에서 `필터·지도 설정`을 기본 접힘으로 제공한다.
- 카테고리를 선택하면 설정을 접고 목록 시작으로 돌아간다.
- 데스크톱 카테고리는 4열로 배치하고, 주소·거리·출처를 유지하면서 카드를 줄였다.
- 결과 부분의 높이를 계속 줄이는 대신 탐색 영역 전체를 스크롤한다.
- 카카오 조회 시각·검색 한도 안내는 페이지 이동 아래에서 펼쳐 확인한다.
- 작은 높이의 데스크톱에서는 탐색 탭의 소개 문구를 생략해 카드 공간을 확보한다.
- 사진이 없는 장소에는 분류 아이콘과 `제공된 실제 사진 없음`을 표시한다.
- 사진 다운로드가 실패하면 분류 그림·오류 안내·다시 불러오기 버튼을 제공한다.
- 한국어·영어 전환과 저장 장소의 오프라인 상세에도 대체 표시가 적용된다.

실제 사진의 출처·크레딧·허용 범위와 원본 비율 처리는 기존 규칙을 사용한다.
관광공사 외 제공처 사진도 같은 검증된 사진 목록에 있으면 표시한다.
이 수정이 새로운 실제 장소 사진을 수집하거나 카카오 사진 API를 추가하는 것은 아니다.
사진이 없는 경우의 그림은 장소 분류 일러스트로 명시한다.
