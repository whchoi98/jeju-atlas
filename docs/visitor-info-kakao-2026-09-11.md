# 방문 정보 부족과 카카오 연동 검토

사용자의 목적은 방문 정보가 충실한 장소 상세입니다.
2026-09-11의 실제 공개 API와 전용 S3 snapshot을 읽어 확인했으며,
이 점검에서 지도 제공처나 장소 데이터를 변경하지 않았습니다.

## 현재 범위

| 항목 | 장소 수 |
|---|---:|
| 전체 카탈로그 | 6,724 |
| OSM 기반 | 6,587 |
| 샘플 시드 | 137 |
| 공식 상세가 연결된 장소 | 344 (약 5.1%) |
| 공식 국문 기록에 이용시간 항목 있음 | 207 |
| 공식 국문 기록에 휴무일 항목 있음 | 199 |
| 공식 국문 기록에 주차 항목 있음 | 197 |
| 공식 국문 기록에 메뉴 항목 있음 | 106 |

항목이 있다는 것은 제공처에 기록이 있다는 뜻입니다.
현재 영업 중인지, 모든 요일이 확인됐는지, 어린이에게 적합한지까지 확정한 집계는 아닙니다.
공식 상세의 사진 183곳도 원본 카탈로그 사진을 합산한 전체 서비스 집계가 아닙니다.

우진해장국은 비짓제주의 주소·전화·소개가 연결되지만 확보된 공식 기록에는
영업시간 항목이나 게시 가능한 사진이 없습니다. 올래국수와 자매국수는
TourAPI의 영업시간·휴무·주차·메뉴 기록이 있습니다. 같은 지역·카테고리라도
장소별 확보 범위가 다릅니다.

카탈로그에는 음식점 5,241곳과 카페 505곳이 있으므로 관광정보 제공처에 없는
장소를 많이 포함합니다. 장소 이름·위치의 존재와 방문 상세의 충실도는 별개입니다.

## 현재 수집 제약

2026-09-11 18:06 UTC snapshot의 마지막 실행은 900곳을 시도했지만 새 상세를
추가하지 못했습니다. 기존 기록은 보존되어 있으며 아래 범주의 새 매칭을 보류했습니다.

| 제공처 | 범주 | 실패 코드 |
|---|---|---|
| VisitJeju 국문 | 음식점 `c4` | `inconsistent_listing_count` |
| VisitJeju 영문 | 음식점 `c4` | `conflicting_listing_identity` |

제공처 페이지의 총건수·고유 ID 불일치와 충돌을 무시해서 다른 장소의 정보를
붙이지 않습니다. 이 제약은 기존 수집기와 [공식 상세 문서](official-details-olle.md)에도 기록돼 있습니다.
다만 두 실패만으로 모든 미보강 장소의 원인을 설명할 수는 없습니다.
수집 순환, 제공처에 장소가 없는 경우, 거리·이름·카테고리 매칭 조건도 범위를 제한합니다.

## 목적에 맞는 구성

1. 기존 3D 화면을 유지하면서 카카오 Local로 장소 ID·이름·주소·좌표·전화·분류·
   카카오 장소 상세 URL을 연결하는 방법을 검토합니다.
2. 이용시간·휴무일·주차·요금·연령·유모차·메뉴는 TourAPI/VisitJeju에서 제공하는
   실제 항목을 출처·조회 시각과 함께 표시합니다.
3. 카카오 상세 페이지의 사진·후기·추가 영업정보는 해당 페이지로 연결합니다.
   Local API 응답에 없는 정보를 API가 제공하는 것처럼 표시하지 않습니다.
4. 정보가 충실한 장소의 우선 노출과 이용정보 필터를 별도로 설계하면
   사용자가 기본 정보만 있는 행을 연속해서 여는 문제도 줄일 수 있습니다.

지도 타일을 교체하는 작업만으로 카탈로그에 새로운 방문 정보가 저장되지는 않습니다.
공식 Local API의 장소 응답에는 사진·후기·영업시간·브레이크타임·주차 항목이 없습니다.
따라서 카카오맵에서 눈으로 볼 수 있는 모든 내용을 현재 앱에 자동 수집하는
구성을 약속할 수 없습니다.

장소 API 연동에는 제주 아틀라스 전용 REST API 키가 필요합니다.
참고 `agentcore-cli`의 키·설정은 가져오지 않습니다.
카카오 지도 화면까지 추가한다면 JavaScript 키와 웹 도메인 등록도 별도로 필요합니다.
위 항목은 구성 검토이며 이번 PWA 배포에 카카오 API 연결이 추가된 것은 아닙니다.
