# 상용 운영 완료 감사

확인일: 2026-09-10 UTC. 이전 목표 턴은 공식 상세·올레길 배포와 실서비스
검증을 완료한 **진행**으로 분류했습니다. 이번 감사에서는 당시 남았던
원본 HTTPS와 추가로 확인한 로그·갱신 감시·버전 복구 공백을 보완했습니다.

**기술 보강은 배포·검증했으나, 운영 수신자와 예산·사업자 정보는 미결입니다.**

## 원본 HTTPS

공개 원본 DNS를 기다리는 방법 외에, AWS가 지원하는 전달 Host 인증서 검증을
사용했습니다. 연결 대상은 기존 ALB의 AWS DNS이며 HTTPS 443만 사용합니다.
숫자 버전 Lambda@Edge는 ALB에 도달하는 세 동작에만 연결하고 Host만
`jeju-atlas.whchoi.net`으로 설정합니다. 본문을 함수에 전달하지 않으며
쿠키·Origin·CSRF·쿼리는 보존합니다. 고도·사진·정적 S3에는 연결하지 않습니다.

임시 CloudFront에서 인증서·한글 쿼리·두 viewer 증명·위조 거절을 확인한 뒤
운영에 적용했습니다. 임시 `Jeju3dTlsProbe`는 비활성화 후 삭제 완료했습니다.
엣지 함수 로그 그룹은 사용 가능한 17개 리전에 14일 보관으로 준비했습니다.

## 로그와 데이터 감시

AWS/Strands 메시지 캡처를 비활성화하고, SDK의 span/log 내보내기 단계에서
원문·도구 인자·예외 텍스트를 제거합니다. 모델·도구 이름, 시간·상태·토큰 수는
유지합니다. 애플리케이션의 인자·원문 예외 로그도 제거했습니다.
실제 영어 방문 계획은 Astra로 53.433초에 완료됐고, 관측한 2,275개 이벤트에서
진단 표식·질문·답변 조각은 발견되지 않았으며 운영 메타데이터는 존재했습니다.

Agent/Tools 전용 로그 두 개는 기존 기록이 모두 14일 이내임을 확인한 뒤
14일 보관을 설정했습니다. 신규 원문 제거와 기존 로그의 보관 기한은 별개입니다.
기존 Memory나 다른 프로젝트의 공유 span 저장 설정은 변경하지 않았습니다.

공식 상세의 상태는 `generated_at`이나 마지막 시도가 아닌 제공처별 `fetched_at`을
기준으로 평가합니다. 빈 자료·로딩 실패·미래 시각·14일 초과 기록은 별도
`official_details_status` heartbeat에서 비정상으로 표시합니다.
실제 정상값 0과 AWS 필터 엔진의 오류값 추출을 모두 확인했습니다.

수집기는 실제 완료 1건과 제공처 오류 3건을 기록했습니다. 오류 알람도 이를
감지했습니다. 비짓제주 연결 오류·목록 건수/동일 ID 충돌은 기존 자료를 유지하며
기록합니다. 갱신 0건만으로 실패 처리하지 않습니다. 완료 누락은 48시간 창으로
평가하므로 초기에는 관측 자료를 기다리는 상태일 수 있습니다.

## 버전 복구와 부하

이전 태스크에 새 JavaScript 파일이 없는 상황을 실제 이미지에서 확인했습니다.
현재·이전 이미지의 자산을 전용 S3에 먼저 게시하고, 충돌 없는 SHA-256 manifest가
있는 이미지만 배포 경로에 연결합니다. 세 버전의 자산 19개가 CloudFront에서
모두 200과 올바른 checksum으로 응답했습니다. 직접 S3 접근과 manifest는 비공개입니다.
존재하지 않는 S3 자산은 `ListBucket` 권한이 없어 403이며, ALB의 없는 경로는 404입니다.

최종 이미지→이전 이미지→최종 이미지를 네트워크 없는 실제 컨테이너로 전환하여
준비 상태·정적 파일·동일 카탈로그·공식 상세를 확인했습니다. 데이터 파일의
hash와 수정 시각은 유지됐습니다. AWS에서는 현재 템플릿·보호 매개변수를 보존하는
이미지 전용 변경 세트를 검토 가능한 상태로 만들었습니다.
**운영 서비스를 이전 버전으로 되돌리는 실험은 실행하지 않았습니다.**
[버전 복구 절차](rollback.md)를 따릅니다.

최종 조회 부하는 50세션·500 GET, 오류 0건, p50 41.702ms,
p95 275.421ms, 최대 502.158ms였습니다. 워밍업은 제외했고 모델 호출은 없습니다.
이는 단기 HTTP 측정이며 브라우저 FPS·최대 AI 사용자·장기 SLA의 증거는 아닙니다.

## 남은 외부 입력

- 운영 알림을 받을 수신자/엔드포인트와 실제 수신 확인
- 예상 트래픽, 월 AWS 예산·AI 예산, 사업자/개인정보 문의처
- 참조 프로젝트 기본 브랜치 병합에 대한 명시적 승인

수신자와 운영 정책 값은 최초 운영 보강부터 세 차례 목표 턴에 걸쳐 미결입니다.
주소나 예산을 추측하거나 승인되지 않은 상대에게 알림을 보내지 않습니다.
참조 `main` 병합은 자동 승인 심사가 명시적 승인이 없다는 이유로 거절했으므로
검증된 코드와 배포 기록은 작업 브랜치에 보관합니다.
참조 프로젝트의 최신 기록은 `jeju-atlas/astra-sol`의 `9d4ae86`입니다.
