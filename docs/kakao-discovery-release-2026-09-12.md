## 검색과 상세

- 자동 선택에서 맛집·카페·숙소·주차장은 카카오 분류 `FD6`·`CE7`·`AD5`·`PK6`를 직접 조회합니다.
- 분류 없는 이름 검색도 카카오를 사용합니다. 자연·관광 분류와 명시적인 기존 카탈로그 선택은 원자료를 사용합니다.
- 카카오 ID·세부 분류·주소·연락처·상세 링크를 처음부터 함께 사용합니다.
- 카카오 목록은 한 페이지 15곳, 검색별 최대 45곳입니다. 제공처의 전체 검색 결과 수와 조회 가능한 수를 구분합니다.
- 카카오 결과를 별도 영구 장소 DB로 수집하지 않습니다. 지도에는 현재 결과 페이지의 장소를 표시합니다.

**필터·지도 설정 → 검색 출처**에서 자동 선택·카카오맵·기존 카탈로그를 바꿀 수 있습니다.
고정된 6,724건 숫자를 카카오 검색 결과 수로 사용하지 않습니다.

현재 선택 결과는 15분 동안 세션에 묶인 서명으로 확인합니다.
상세 화면은 이 결과를 재사용해 같은 이름을 카카오에서 다시 찾지 않습니다.
이후 저장 장소를 다시 열 때는 현재 검색에서 같은 카카오 ID를 확인하며,
확인할 수 없으면 저장 정보임을 표시합니다.
선택 토큰·현재 조회 원문은 여행 스냅샷이나 PWA 캐시에 넣지 않습니다.

## 공공정보와 이전 여행

사진·이용시간·편의 정보는 같은 장소로 연결할 수 있는 기존 기록에만 붙입니다.
이름·분류·거리로 확인하고 동명이인, 부속 시설, 불완전한 결과는 임의로 연결하지 않습니다.
원본 이름·주소·좌표를 바꾸지 않고 출처별 근거·이용허락·확인 시각을 유지합니다.

공공 자료가 너무 크거나 일부 형식이 맞지 않아도 카카오 기본 연락처와 링크는 유지합니다.
기존 여행·즐겨찾기 ID와 새 `kakao:` ID가 함께 저장되며, 선택 토큰은 저장·백업에서 제외됩니다.
운영 협재해수욕장 `poi_0057`의 기존 좌표·ID와 사진 5장·공식 상세 3건도 확인했습니다.

## AI 가이드

상업 장소의 조회는 BFF의 공용 카카오 서비스·일일 한도·세션 제한을 사용합니다.
Tools Runtime에 키를 추가하거나 별도 무제한 호출 경로를 만들지 않았습니다.
선택 토큰 검증은 AI 사용량 승인 전에 수행하고, 필요한 외부 조회는 승인 후에 수행합니다.

질문 원문과 분리한 현재 조회 근거를 Guide에 전달합니다.
선택 토큰은 모델에 전달하지 않으며, 조회 원문은 장기 Memory에 저장하지 않습니다.
모델이 반환한 카카오 ID·좌표·출처는 해당 요청의 실제 조회 결과로 확인합니다.
새 데이터 지원 여부는 스트림 버전 확인으로 검증하며 이전 실행 환경은 새 대화를 안내합니다.

운영 검증에서는 다음 완료 응답을 확인했습니다.

- **선택 장소:** 올래국수 본점의 이름·연락처 `064-742-7355`·Kakao Local/TourAPI 출처.
- **주변 추천:** 협재해수욕장 주변 호텔샌드·카페모래알의 주소와 Kakao Local 출처.

주변 추천의 최종 검증은 05:22:20 UTC에 완료됐으며 약 13.7초가 걸렸습니다.
이는 해당 검증 요청의 측정값이며 일반 응답 시간 보장은 아닙니다.

초기 운영 검사에서 협재해수욕장의 서로 다른 원본 ID 두 개가 기준점 선택을 막았습니다.
최종 보완은 이름이 같은 자연 명소가 모두 200m 안에 있고 지정 분류 또는 이름으로
기준점을 정할 수 있을 때만 처리합니다. 업소 동명이인·다른 자연 유형·먼 장소는 계속 구분합니다.
이 처리는 주변 검색의 기준점만 정하며 원자료나 상세 보강 기록을 합치지 않습니다.
