## 연결되지 않은 이유

카카오 API 호출은 정상적으로 인증됐지만 앱의 매칭 조건이 실제 장소를 제외했습니다.

- `올래국수`는 카카오에 `올래국수 본점`으로 등록되어 이름 전체 일치 조건에서 제외됐습니다.
- `성산일출봉`은 카카오의 큰 분류 코드가 비어 있고 세부 분류에 `여행 > 관광,명소 > 산봉우리`가 있습니다.
  기존 코드는 큰 분류 코드로 검색했기 때문에 해당 장소를 조회하지 못했습니다.
- 미검증 시드를 처음부터 2km 범위로 조회하면 부속 시설 등 검색 결과가 많아집니다.
  결과가 최대 조회 건수에 도달하면 유일한 장소임을 확인할 수 없어 연결을 보류했습니다.
- 이름·위치 차이, 동명이인, 실제 검색 결과 없음도 발생할 수 있습니다.
  이전의 일괄 안내문만으로는 어느 경우인지 알기 어려웠습니다.

## 변경한 동작

먼저 200m 안의 결과를 거리순으로 조회합니다. 결과가 완전하고 이름·분류·거리 조건을 충족한 장소가
하나이면 연결합니다. 완전한 가까운 검색에서 연결할 곳이 없는 미검증 시드에 한해 2km를 다시 확인합니다.
OSM 장소는 기존 200m 범위를 유지합니다.

큰 분류 코드가 없는 장소도 조회한 뒤 세부 분류를 검토합니다.
단순히 코드가 없다는 이유로 허용하지 않으며, 다른 업종과 주차장·화장실 같은 부속 시설을 구분합니다.
등록명에 `본점`만 추가된 경우에는 원래 이름 전체가 일치하고 거리가 100m 이내일 때만 검토합니다.
다른 지점명이나 지역 접두사를 임의로 제거하지 않습니다.

같은 이름의 후보가 여러 개이거나 검색 결과가 불완전하면 자동 연결을 확정하지 않습니다.
조회는 기존 일일 한도, 동시 실행 제한, 전체 제한 시간 안에서 최대 6회입니다.

연결하지 못한 경우 한국어와 영어로 다음 이유를 구분합니다.

| 응답 사유 | 화면에서 설명하는 내용 |
| --- | --- |
| `no_results` | 현재 이름과 위치로 검색 결과가 없음 |
| `name_mismatch` | 등록 이름 또는 지점명 차이 |
| `category_mismatch` | 장소 분류 차이 |
| `distance_mismatch` | 등록 위치 차이 |
| `multiple_candidates` | 같은 이름의 후보가 여러 곳 |
| `incomplete_results` | 결과가 많거나 일부만 확인됨 |

확정되지 않은 장소에는 카카오맵 이름 검색 링크를 제공합니다.
기존 카탈로그의 ID·이름·좌표·출처는 유지하고 카카오 정보는 별도 카드에서 표시합니다.
워크숍 10장과 배포된 PC 교재에도 조회 기준을 반영했습니다.
