# 제주 아틀라스 상용 운영 보강

사용자 목표: 상용서비스 수준으로 보강. 확인일: 2026-09-10.

## 범위와 유지 조건

제주 3D 지도·장소 카탈로그·여행 코스·AI 가이드를 제공하는 현재 서비스를
기준으로 운영 안정성, 비용 제어, 데이터 신뢰성, 사용성, 복구 능력을 보강합니다.
`cc-on-bedrock-vpc`의 기존 Public/Private 서브넷과 NAT Gateway를 재사용하고,
전용 ALB는 Public, Fargate는 Public IP 없이 Private에 유지합니다.

처음에는 대표 명소만 보이는 지도, 카테고리·주변 탐색, 나눔스퀘어, 안전한
마크다운·이모지·실제 도구 상태·생각중 표시·항상 보이는 추천 질문을 보존합니다.
기존 Ohmyjeju AgentCore와 S3 카탈로그를 연계합니다. 2026-09-10 사용자가
명시적으로 요청한 모델 변경은 기존 Agent 런타임에 반영하며, 카탈로그 원본과
Tools·Gateway·Memory의 구성은 보존합니다.

추가 사용자 요구: 서울 Global CRIS를 우선 사용하고, 한국어/영어 선택 토글로
화면과 AI 답변 언어를 바꿉니다. 일반 질문은 `global.openai.gpt-5.6-sol`,
일정·코스 계획은 `global.openai.gpt-6-astra`로 라우팅합니다.

합성 요청의 잠정 성능 기준은 서울 측정 호스트에서 동시 50세션의 카탈로그·설정
요청에 대해 오류 0건, p95 1초 이하입니다. 외부 지도 공급자와 모델 응답의 시간은
별도로 측정합니다. 이 값은 계약된 SLA나 장기간 가용성의 증거가 아닙니다.

## 설계 선택

1. 서버에 분산 입장 제어를 먼저 적용한 뒤 ECS를 이중화합니다. 기존 일일 30회,
   사용자 시간당 5회, 전체 동시 2회 보호 한도는 운영 예산이 정해지기 전까지
   유지하되 배포 설정으로 명시합니다. 한도 초과 요청을 모델에 보내지 않습니다.
2. 여러 카운터와 실행 잠금을 하나의 DynamoDB 입장 작업으로 처리합니다.
   잠금에는 만료와 소유자를 두고, 만료 정리는 DynamoDB TTL 삭제 시점에
   의존하지 않습니다. 모델 호출의 불명확한 네트워크 실패는 자동 재호출하지 않습니다.
3. 살아 있는 프로세스와 요청을 받을 준비가 된 프로세스를 구분합니다.
   종료 시 신규 요청을 중단하고 이미 시작한 스트림이 제한 시간 안에 완료되도록 합니다.
4. 사용자 도메인과 인증서를 코드에 반영한 뒤 CloudFront 부가 설정을 배포합니다.
   DNS 위임이 없는 Zone을 조작해 TLS가 준비된 것처럼 취급하지 않습니다.
5. WAF·관측 리소스는 아틀라스 전용 스택으로 관리합니다. 지도 타일 요청은
   API 빈도 제한에서 제외하고 로그에 질문·답변·쿠키·토큰을 남기지 않습니다.
6. 공식 소스의 부가 정보가 연결되었다는 이유만으로 샘플 기본 필드를 검증 완료로
   표시하지 않습니다. 상업 이용 라이선스가 확인되지 않는 사진은 표시하지 않습니다.
7. 사용자 여행 자료는 현재 브라우저 저장 모델을 유지하면서 내보내기·삭제·복원을
   제공합니다. 계정·결제·서버 동기화는 사용자의 추가 제품 요구가 없는 상태에서
   임의로 도입하지 않습니다.
8. 모델은 기존 AWS IAM과 Bedrock Converse 인터페이스로 호출합니다. 실제 검사에서
   두 Global 프로필의 `reasoning.effort`와 도구 호출이 정상 동작했습니다.
   OpenAI 모델에는 Claude 전용 추론 필드와 명시적 캐시 포인트를 보내지 않습니다.
9. 언어 선택은 모델 선택과 별개입니다. 요청마다 `locale`을 고정하고 안전한 인증
   복구에서도 같은 언어와 `request_id`를 유지합니다. 번역되지 않은 장소 고유명과
   출처 원문은 보존하며 확인되지 않은 영어 공식 명칭을 만들지 않습니다.

## 운영자가 정해야 하는 값

- 예상 동시 사용자·월 AWS 예산·AI 호출 예산
- 장애 알림 담당자와 실제 수신 경로
- 원본 TLS에 사용할 공개 DNS 레코드 또는 현재 DNS 관리 권한
- 개인정보 처리 책임자·연락처와 실제 약관에 필요한 사업자 정보

확인되지 않은 값은 완료 보고에서 누락하지 않습니다. 코드·인프라 검증을
마쳤더라도 외부 DNS나 알림 수신이 남아 있으면 해당 기준은 미완료입니다.
