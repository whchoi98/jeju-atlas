# AI 이용 한도 해제와 접속 집계

전체 목표는 **카카오맵의 디자인·기능 아이디어를 참고해 제주 아틀라스의 기능과 편의성을 확대하는 것**이다.
사용자가 우선 요청한 AI 한도 해제와 접속 수 표시는 이 목표의 첫 배포 단계다.
이 단계의 완료만으로 전체 지도 기능 확장 목표를 완료 처리하지 않는다.

1. `GUIDE_LIMITS_ENABLED=false`일 때 앱의 일일·시간당·전체 동시·사용자별 동시 이용 한도를 적용하지 않는다.
   서로 다른 브라우저와 독립 대화는 함께 처리한다.
2. 같은 요청 ID의 중복 실행, 결과 불명 요청의 재실행, 같은 대화의 동시 갱신은 계속 방지한다.
   인증·CSRF·입력 검증과 요청 제한 시간은 유지한다.
3. 현재 접속 수는 최근 90초 동안 접속이 확인된 서명된 브라우저 세션 수다.
   30초 간격으로 갱신하며 여러 탭과 새로고침은 같은 세션으로 집계한다.
4. 누적 수는 집계 도입 이후 각 브라우저 세션의 첫 접속을 한 번씩 더한다.
   실제 사람의 수나 과거 접속 통계를 추정하지 않는다.
5. 집계는 ECS 태스크가 공유하는 전용 DynamoDB 테이블에 저장한다.
   활성 기록은 TTL로 정리하되 현재 접속 계산은 시각 조건으로 판정한다.
   누적 등록 기록과 합계는 재배포 후에도 유지하고 원자적으로 갱신한다.
   동시 갱신 중인 활성 브라우저를 과거에 잡은 조회 상한으로 제외하지 않는다.
   같은 출처의 최초 설정 요청은 Web Locks로 직렬화하여 쿠키 없는 창들의 세션 발급 경합을 막는다.
   창 간 조정을 지원하지 않는 환경에서는 다른 앱 기능을 유지하고 접속 등록은 확인 불가로 처리한다.
6. API는 집계 수와 기준 시각만 반환한다. IP·검색어·좌표·대화·브라우저 세션 ID를 공개하지 않는다.
   집계 실패나 오프라인 상태를 0명으로 표시하지 않는다.
7. 한영 UI에서 `접속 N · 누적 M`을 작은 한 줄로 표시한다.
   지도·목록·AI·PWA의 기존 공간과 기능을 유지한다.
8. 기존 프로젝트·AgentCore·VPC·NAT·모델 선택을 변경하지 않는다.
   접속 테이블과 해당 테이블에 한정한 IAM 권한만 추가한다.
9. 운영 사이트의 독립 브라우저 동시 AI 응답과 접속 집계, 새로고침 중복 방지,
   기존 카드 표시·PWA를 검증한다. 실제 모델 시험은 최소 요청으로 진행한다.
10. 새 대화 조정 코드를 기존 제한 모드로 먼저 배포하고 이전 프로세스를 종료한 뒤,
    같은 이미지의 `GuideLimitsEnabled`만 false로 바꾼다. 최종 운영 설정은 false다.
