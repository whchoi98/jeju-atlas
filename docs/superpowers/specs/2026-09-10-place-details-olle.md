# 공식 장소 상세와 올레길 테마 확장

사용자 추가 요구(2026-09-10):

- 사진과 기본정보를 가져오는 방법을 마련하고 부족한 장소 상세를 보강.
- 제공한 비짓제주·국문 TourAPI 키를 사용.
- 둘러보기에 제주 한 바퀴 외 제주 올레길 테마를 추가.

## 장소 상세

키는 아틀라스 전용 SSM SecureString에 저장합니다. 브라우저·소스·이미지·로그에
키 값을 넣지 않습니다. 실제 서비스 호출에서 두 키의 정상 응답을 확인했습니다.

공식 API 수집은 별도 작업으로 수행하고, 검증한 결과를 아틀라스 전용 비공개
S3 스냅샷 `place-details/latest.json`으로 발행합니다. 기존 원본 카탈로그는
읽기 전용으로 유지합니다. 앱은 마지막 정상 스냅샷을 사용하여 상세를 빠르게
표시하고, 수집 장애가 지도·기본 카탈로그 장애로 이어지지 않도록 합니다.

추가 계약:

```text
version: 1
generated_at: ISO timestamp
records:
  <기존 장소 ID>:
    - provider: tourapi | visitjeju
      provider_id, locale, source_url, fetched_at, title
      address, phone, website, latitude, longitude, overview
      facts: [{key, label_ko, label_en, value}]
      photos: [기존 사진 계약]
      match: {method, distance_m}
```

이름·분류·지역과 후보의 유일성을 검사합니다. 좌표가 미검증인 시드에 150m 조건만
적용해 대표 명소가 누락되는 문제를 보완하되, 다른 지점·동명이소·모호한 후보를
자동 확정하지 않습니다. 매칭 방법과 출처를 남기고 `reviewed`로 자동 승격하지
않습니다. 원본 ID·좌표를 덮어쓰지 않고 공식 상세를 별도 필드로 제공합니다.

TourAPI 공통·소개·반복 정보·이미지에서 소개, 주소, 전화, 홈페이지,
이용시간·휴무일·요금·주차·접근 정보 등을 가져옵니다. 비짓제주의 설명,
주소·전화·태그를 보완 자료로 사용합니다. 원문에 없는 값은 생성하지 않습니다.

사진은 항목별 이용 조건이 확인된 것만 사용합니다. KOGL-1/3 등 허용 목록과
출처를 검사하고, 변경 금지 사진은 원본 바이트를 유지합니다. 키가 유효하다는
사실만으로 모든 비짓제주 사진의 상업 이용이 허용된 것으로 보지 않습니다.
허용된 사진은 전용 S3의 `media/`에 보관하고 CloudFront로 제공합니다.

화면은 큰 사진·갤러리, 공식 소개, 연락처와 홈페이지, 이용 정보를 중심으로
구성합니다. 한영 선택을 유지하고 공식 영문이 없으면 원문을 보존합니다.
공식 정보와 원래 시드 정보의 출처를 구분합니다. AI의 장소 상세 도구에서도
같은 보강 정보를 사용할 수 있도록 연결합니다.

## 올레길 둘러보기

기존 제주 한 바퀴를 유지하며 코스별 선택을 제공합니다. 공식 GPX 또는
OpenStreetMap의 실제 선형 경로를 확보해 출처·기준일과 함께 표시합니다.
직선으로 이어 붙인 경로를 실제 보행 경로로 표시하지 않습니다.

선택한 코스의 경로, 거리와 출처를 보여 주고 경로를 따라 3D 카메라가 이동합니다.
Escape·중지 버튼·수동 지도 조작으로 종료할 수 있어야 합니다.
연결되지 않은 지오메트리는 임의로 이어 붙이지 않습니다. 자료가 없는 코스나
기존 지도 범위를 벗어난 코스는 지원 상태를 명확히 표시합니다.

## 검증

- 비밀 값이 저장소·응답·브라우저 번들·로그에 포함되지 않음.
- 실제 대표 명소의 사진·기본정보·이용 정보가 이전보다 증가함.
- 모호한 장소 매칭·허용되지 않은 사진은 게시되지 않음.
- 수집 실패·부분 수집이 마지막 정상 자료를 지우지 않음.
- 새 정보가 장소 상세와 AI 상세 도구에 출처와 함께 전달됨.
- 공식 자료 스냅샷과 미디어의 버전·갱신 상태를 확인할 수 있음.
- 올레길 테마가 실제 경로를 표시하고 재생·중지·한영·모바일에서 동작함.
- 기본 지도·카탈로그·가이드·저장 자료·두 AZ 구성이 유지됨.
