# 카카오맵에서 참고한 제주 탐색 경험 확장

목표는 카카오맵의 디자인·기능 아이디어를 제주 아틀라스의 실제 검색·장소 선택·길찾기·재방문 흐름에 적용하는 것이다.
카카오맵 공개 화면의 검색·길찾기·MY, 주변 분류, 현재 위치, 자주 쓰는 장소를 참고했다.
참고 화면은 `.local/kakao-map-experience-20260912/reference/`의 2026-09-12 HTTP 200 캡처에 있다.

## 완성 기준

1. **검색:** 검색창의 지우기·즉시 검색, 최근 검색과 현재 결과에 기반한 후보 선택, 키보드 탐색을 제공한다.
   후보를 누르면 해당 장소 또는 검색으로 이어진다. 부분 입력마다 검색 기록을 저장하지 않는다.
2. **저장:** 기본 탐색 도구에 저장 탭을 추가한다. 즐겨찾기·최근 본 장소·최근 검색을 다시 열고,
   즐겨찾기 안에서 검색·분류하거나 자주 쓰는 장소를 최대 5개 고정할 수 있다.
3. **길찾기:** 출발·도착 장소를 이름으로 검색하고 지도·저장 장소에서도 지정한다.
   출발·도착 선택 순서와 무관하게 의도한 경로가 만들어져야 하며 임의 출발지를 만들지 않는다.
   중간 경유지를 유지하는 편집과 전체 순서 뒤집기를 제공한다.
4. **지도:** 명시적인 `이 지역에서 검색`, 현재 위치, 우클릭·터치 길게 누르기·키보드 지점 동작을 제공한다.
   선택 지점에서 출발·도착·주변 탐색·좌표 복사를 실행한다.
5. **목록·상세 연결:** 목록의 포인터·키보드 초점이 지도에서 해당 위치를 강조한다.
   장소 주소 복사와 장소 공유를 쉽게 실행할 수 있다.
6. **실사용 조건:** 한영 전환, AWS 색상·나눔스퀘어, 3D/실제 도로 경로, 지도 드래그·회전·핀치,
   모바일 목록 2개 이상, 사이드바 접기, 즐겨찾기·코스·PWA를 유지한다.
7. **정확한 상태:** 최근 기록은 브라우저에 제한된 수·기간으로 저장하며 삭제와 저장 불가 상태를 제공한다.
   카카오 선택 토큰·인증 정보는 기록에 넣지 않는다. 저장 장소를 열면 기존의 동일 ID 갱신 경로를 사용한다.
   위치 권한은 사용자가 버튼을 선택할 때 요청하며 제주 밖·거절·실패는 명확하게 안내한다.
8. **검색 품질:** 운영 검증에서 발견한 성산일출봉 기준점·아이 동반 추천의 미검색 원인을 조사하고,
   확인된 원인에 맞는 수정과 실제 질문 검증을 포함한다.
9. **배포:** 워크숍 안내·변경 기록을 갱신하고 로컬·공개 브라우저와 AWS 배포를 검증한다.
   기존 `agentcore-cli`와 네트워크, 한도 해제·접속 집계 구성의 독립성을 유지한다.

최근 검색·저장·출발/도착 등 이용 동작을 차용한다. 지도 배경과 사진·평점·교통 정보는
실제 구현된 데이터 출처 범위를 따르며, 없는 데이터를 화면 장식으로 생성하지 않는다.
현재 접속 집계 배포만으로 이 전체 목표를 완료 처리하지 않는다.
