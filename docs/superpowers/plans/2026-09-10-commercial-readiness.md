# 상용 운영 보강 실행 계획

관련 설계: `../specs/2026-09-10-commercial-readiness.md`.
참고 구현: `agentcore-cli-main` `9e42038`; 조사 기록: `../../reference-review.md`.

## 작업 순서

1. [x] 현재 코드·AWS 설정·최신 참고 프로젝트를 읽고 차이와 완료 기준 기록.
2. [x] 사용자 도메인·인증서·배포 매개변수 보존, 실배포 설정 검증.
3. [x] 분산 사용량·동시 실행·중복 요청 제어, 준비 상태와 점진 종료.
4. [x] 상업 이용 사진 정책·필드별 출처와 데이터 품질 검사.
5. [x] 여행 자료 내보내기·복원·삭제, 저장 실패·오프라인·접근성 보강.
6. [x] 전용 WAF·로그·알람·대시보드, 2개 AZ와 제한된 자동 확장 IaC.
7. [ ] 공개 DNS·인증서 조건이 충족된 원본 HTTPS 설정.
8. [x] 단위·계약·빌드·템플릿·이미지 검사 후 변경 세트 검토.
9. [x] 기존 VPC·NAT를 유지한 배포와 양쪽 도메인 HTTP·사용자 도메인 브라우저 회귀 검사.
10. [x] 모델 호출 없는 부하·태스크 교체·복구 검사, 필요한 최소 실제 AI 검사.
11. [x] 운영 지침·검증 결과·비용과 미충족 기준을 기록.
12. [x] 서울 Global CRIS Sol/Astra 모델 전환과 기존 Agent 런타임의 제한된 갱신.
13. [x] 한국어/English 토글·선택 저장·API locale 전달·양쪽 언어 회귀 검사.

검증 결과: `../../commercial-release-2026-09-10.md`.
미완료: 원본 DNS/HTTPS 전환, 알람 수신 확인, 운영 예산·담당자 정책.

## 병렬 작업 경계

- 서버: 분산 입장 제어, AI 전송, API 준비 상태, 종료 처리와 관련 테스트.
- 데이터: 카탈로그 읽기, 상업 이용 사진, 필드 신뢰도와 데이터 테스트.
- UI: 기존 지도·AI 흐름을 보존한 저장 자료 관리·접근성과 브라우저 검사.
- 운영: 별도 edge/operations 템플릿과 검증. 공통 앱 템플릿·배포 스크립트는
  통합 담당자가 변경하여 충돌을 피합니다.

## 검증과 중단 조건

- 모델 호출은 명시적인 실제 AI 검사에서만 사용하고 일반 회귀·부하 검사는 모킹합니다.
- 여러 태스크용 분산 제어가 검증되기 전에는 운영 태스크 수를 늘리지 않습니다.
- 변경 세트가 공유 네트워크, 다른 서비스, 사용자 데이터 삭제·교체를 요구하면
  해당 배포를 실행하지 않고 범위를 다시 검토합니다.
- 기존 이미지 digest와 변경 전 설정을 보관하고 실패 시 해당 릴리스로 복구합니다.
- 각 완료 기준은 새 결과 파일과 실행 명령으로 평가합니다. 과거 테스트 결과만으로
  새 릴리스가 검증되었다고 보고하지 않습니다.
