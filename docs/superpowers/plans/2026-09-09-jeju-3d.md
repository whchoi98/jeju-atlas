# Jeju 3D Implementation Plan

> **For agentic workers:** Apply the installed dispatching-parallel-agents workflow for the independent frontend, with infrastructure and integration owned by the parent.

**Goal:** 실제 제주 지형을 탐색하는 한국어 앱을 지정 AWS 네트워크에 공개 배포한다.

**Architecture:** 브라우저에서 MapLibre가 실제 DEM과 위성 타일을 렌더링한다. CloudFront가 Public ALB 앞에서 정적 앱을 캐싱하고 ALB는 검증된 요청만 Private ECS Fargate로 전달한다. 기존 VPC·서브넷·NAT를 재사용한다.

**Tech Stack:** TypeScript, Vite, MapLibre GL JS, Node.js, Docker ARM64, CloudFormation, boto3, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-09-jeju-3d-design.md`

- 한국어·실제 DEM·명시적 고도 배율·지도 출처·모바일·키보드·reduced motion.
- 승인된 배포 요청 범위에서 구현과 배포를 이어 수행한다.
