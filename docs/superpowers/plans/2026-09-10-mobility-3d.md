# Mobility and 3D Implementation Plan

> **For agentic workers:** Use subagent-driven-development or executing-plans to implement this plan task by task. Each worker owns the files assigned below.

**Goal:** 제주에서 실제 도보·차량 경로와 예상 시간을 제공하고 여행 계획·주요 명소 3D·고도·측정을 함께 사용할 수 있게 한다.

**Architecture:** 제주 OSM로 만든 고정 버전 Valhalla 그래프를 기존 Fargate 작업의 내부 사이드카로 실행한다. Node BFF가 검증·세션·부하 제한을 맡고 기존 TripPlanner와 MapLibre 화면이 결과를 보여준다.

**Tech Stack:** Node 24.18.1+, TypeScript 5.9.3, MapLibre 6.9.0, Valhalla 3.8.3 ARM64, OSM, CloudFormation.

**Spec:** `docs/superpowers/specs/2026-09-10-mobility-3d.md`

## Global Constraints

- `.env*` 및 자격증명 파일을 읽거나 키 값을 출력하지 않는다.
- 기존 VPC, Public ALB, Private ECS, NAT, CloudFront HTTPS origin, 카탈로그·AI 보호를 유지한다.
- 실제 도로 경로와 직선 측정을 구분한다. 실시간 교통·사진측량 모델을 사칭하지 않는다.
- 나눔스퀘어와 한국어/영어를 모두 지원한다.
- `POST /api/routes`는 2–12개 제주 좌표만 수용한다.
- 작업 공간: `/home/ec2-user/my-project/jeju-3d-mobility`, branch `jeju-atlas/mobility-3d`.
- `agentcore-cli` 소스·스택·역할·메모리는 읽기 전용 참조다. 제주가 소유한 AgentCore와 코드·카탈로그 사본으로 독립시킨다.
