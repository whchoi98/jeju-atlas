## 화면과 지도 조작

헤더 왼쪽 버튼으로 데스크톱 사이드바를 접고 펼칩니다.
접으면 지도 영역이 넓어지며, 다시 펼칠 때 선택한 탭·검색·AI 대화·작성 중인 질문을 유지합니다.
숨겨진 영역은 키보드·보조기기 입력 대상에서 제외하고 모바일에서는 기존 서랍을 사용합니다.
검색 단축키처럼 사이드바가 필요한 동작은 다시 펼칩니다.

AI 탭은 화면 크기에 따라 360~520px로 넓어집니다.
1440px 화면 검사에서는 대화 폭이 299px에서 479px로 증가했습니다.
소개 제목은 한국어·영어 모두 한 줄이며 나침반 질문은 16px로 줄였습니다.
도보·차량 선택 카드는 각각 120px로 줄이고 선택·키보드 접근을 유지했습니다.

기존 코드는 드래그·회전 시작 시 `map.stop()`을 호출하면서 입력 핸들러도 초기화했습니다.
자동 재생 중단과 사용자 제스처를 구분하여 첫 움직임 뒤에 끊기던 문제를 수정했습니다.
마우스 드래그·회전, 휠·키보드 이동, 한 손가락 이동·두 손가락 확대를 실제 브라우저 입력으로 검사했습니다.
기존 둘러보기·경로 미리보기·거리 재기도 회귀 검사했습니다.
이 수정은 먼저 `release-20260911T211518Z` / 태스크 14에 배포했고 현재 릴리스에도 포함됩니다.

## 실제 카카오 REST 연동

장소 상세를 열면 인증된 ECS BFF가 기존 카탈로그 ID로 장소를 찾고 카카오 Local을 조회합니다.
주소·전화·카카오 상세 링크와 조회 시각을 별도 카드로 표시합니다.
운영 우진해장국(`poi_0093`)에서 카카오 장소 `11547525`의 실제 응답과 화면 표시를 확인했습니다.
한영 전환은 현재 열어 둔 조회 결과를 다시 표시하며 불필요한 제공처 호출을 만들지 않습니다.

```text
GET /api/kakao/place?id=<canonical catalog ID>
```

서명된 세션 쿠키와 `X-Atlas-CSRF` 증명이 필요합니다.
클라이언트가 임의 검색어·좌표·URL을 제공하는 프록시는 아닙니다.
카카오 키는 서버의 Authorization 헤더에만 사용하고 브라우저 설정에는 전달하지 않습니다.

매칭은 이름·허용된 분류·거리와 후보의 유일성을 검사합니다.
호환 분류를 각각 조회하고 분류당 3페이지, 전체 최대 6회 요청으로 제한합니다.
중복 충돌·누락·검색 상한 때문에 완전성을 확인하지 못하면 확정 매칭하지 않습니다.
OSM은 200m, 미검증 시드 좌표는 2km 이내를 사용합니다.

기존 ID·이름·좌표·출처를 바꾸거나 카카오 결과를 카탈로그 DB·PWA 캐시에 저장하지 않습니다.
연결되지 않은 장소는 이름 검색 링크를 제공합니다. 같은 장소를 독립적으로 검토했다는 의미는 아닙니다.
예를 들어 본점 표기 차이, 제공처 분류, 결과가 없는 경우에는 자동 연결되지 않을 수 있습니다.

Local API는 사진·후기·영업시간을 제공하지 않습니다.
이용시간·휴무일·주차·요금은 기존 TourAPI/VisitJeju 자료를 유지하고 추가 방문 정보는 카카오 상세 페이지로 연결합니다.
카카오 장애·한도·불명확한 매칭이 기존 장소 상세를 막지 않습니다.

이번 연동은 **ECS 장소 상세 BFF**입니다.
3D 지도는 기존 MapLibre·지형·위성 구성을 사용하고 AgentCore Guide/Tools의 모델·도구는 변경하지 않았습니다.
JavaScript SDK나 네이티브 앱 키를 사용하지 않아 해당 SDK의 도메인 인증과 별개로 작동합니다.

## 키와 자원 경계

- `/jeju-atlas/kakao-rest-api-key`를 전용 SSM SecureString으로 저장했습니다.
- ECS 실행 역할만 정확한 해당 파라미터 ARN을 읽으며 컨테이너에는 secrets로 주입합니다.
- 카카오 HTTP 호출은 AI 사용량과 별도인 DynamoDB 카운터로 하루 최대 1,000회 제한합니다.
- 세션당 분당 20회, 태스크 내 동시 조회 2개와 전체 조회 제한 시간을 적용합니다.
- VPC·서브넷·NAT·라우터·AgentCore·참고 프로젝트는 변경하지 않았습니다.
- 워크숍에도 `set-secret --provider kakao`와 팀 전용 경로·최소 권한 설정을 추가했습니다.
