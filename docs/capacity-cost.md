# 용량과 비용 기준

현재 배포·검증 상태는 [운영 검증 종합 기록](commercial-completion-audit-2026-09-10.md)을
기준으로 합니다. 아래 금액은 명시한 사용량 가정의 계산이며 월 총액 보장이 아닙니다.

## 앱 용량

2026-09-10 AWS Price List `GetProducts`로 서울 리전 Linux ARM Fargate 가격을
확인했습니다. 요율은 vCPU 시간당 **USD 0.03725**, 메모리 GB 시간당
**USD 0.00409**입니다.

태스크 하나는 0.25 vCPU·0.5 GB입니다. 한 달을 730시간으로 가정하면:

| 구성 | Fargate CPU·메모리 예상 비용 |
|---|---:|
| 태스크 1개 | USD 8.29/월 |
| 최소 태스크 2개 | USD 16.58/월 |
| 최대 태스크 4개가 한 달 내내 실행됨 | USD 33.16/월 |

최소 2개는 AZ 이중화용이며, CPU 60%·메모리 70% 목표에 따라 최대 4개까지
확장합니다. 배포 때 실제 태스크 수가 이미 늘어났다면 최소값으로 강제로
되돌리지 않습니다.

최종 웹 `release-20260910T202150Z`의 50개 세션·500 GET 검사에서 오류 0건,
p50 41.702ms·p95 275.421ms·최대 502.158ms를 관측했습니다.
짧은 HTTP 검사로 장시간 처리 용량이나 동시 사용자 수를 확정하지 않습니다.
예전 82ms대 p95와의 차이를 성능 개선율로 해석하지 않습니다.
[부하 검사 범위](load-recovery.md) · [측정 원문](../.local/load-final-commercial.json)

## 원본 HTTPS 함수

`jeju-3d-origin-host:1`은 기본 동작과 두 API 동작의 **ALB 원본 요청**에서만
실행합니다. CloudFront 캐시 적중에는 실행하지 않으며 비캐시 API 요청은 원본으로
전달됩니다. `/assets/*`, `/media/*`, `/terrarium/*`에는 이 Lambda@Edge를 연결하지 않습니다.

2026-09-10에 확인한 AWS Price List의 Lambda@Edge 요율:

| 항목 | USD 단가 |
|---|---:|
| 요청 | 100만 건당 0.60 |
| 실행 | GB-second당 0.00005001 |

**128 MB(0.125 GB), 요청당 10ms**를 가정해 ALB 원본 요청 100만 건을 계산하면:

```text
요청: 1,000,000 × 0.0000006 = USD 0.60
실행: 1,000,000 × 0.125 × 0.010 × 0.00005001 = USD 0.0625125
합계: 약 USD 0.6625
```

10ms는 비용 설명을 위한 가정이며 운영 실행 시간 측정값이 아닙니다.
전체 viewer 요청 100만 건의 비용으로 해석하지 않습니다.
이 예시는 다른 AWS 서비스·세금·할인·무료 제공량을 포함하지 않습니다.
가격 근거: [Lambda@Edge Price List 기록](../.local/lambda-edge-pricing.json).

## 총액에 별도로 포함할 항목

위 계산에는 ALB 시간·LCU·공인 IPv4, 기존 NAT의 추가 처리량, CloudFront 요청·전송,
S3 공유 자산·공식 상세·사진의 저장·요청·이전 버전, 일일 수집 Fargate,
ECR·Secrets Manager·DynamoDB, WAF·로그·알람·대시보드,
AgentCore·모델 토큰 비용이 포함되지 않습니다. 기존 NAT 시간당 비용을 새로
만들지는 않지만 추가 트래픽의 처리량은 발생할 수 있습니다.
과거 태스크 1개 기준의 USD 35–45 예시는 현재 서비스의 총액 견적이 아닙니다.

## 운영자가 정할 값

AI는 현재 전체 하루 30회·사용자 시간당 5회·전체 동시 2회 제한을 공유합니다.
이는 요청 입장 한도이며 금액 상한이나 모델 토큰 상한은 아닙니다. 도구 사용과
대화 길이에 따라 한 요청 안의 모델 호출·입출력 토큰 수가 달라집니다.
예상 사용자 수·트래픽, 월 예산과 경보 기준, 알림 수신자가 아직 확정되지 않았습니다.
이 입력을 받은 뒤 호출 한도·예산 알림·접근 정책을 함께 조정해야 합니다.
임의의 사업자·서비스 연락처나 금액 상한을 확정하지 않습니다.

가격 근거: AmazonECS, `location=Asia Pacific (Seoul)`, ARM 요율,
SKU `27GM5GDE29DV8J8U`와 `HNBF4GM42YHAVRU3`.
확인 원문은 [Fargate 가격 기록](../.local/fargate-pricing.json)에 보관합니다.
