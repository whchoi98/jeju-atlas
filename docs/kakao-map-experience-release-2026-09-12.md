# 검색·저장·길찾기와 지도 조작 확장

카카오맵 공개 화면의 검색·길찾기·MY, 주변 분류, 현재 위치, 자주 쓰는 장소에서
이용 흐름을 참고했다. 제주 아틀라스의 AWS 색상·나눔스퀘어·실제 3D 지도와 기존
카카오 Local·카탈로그·Valhalla·전용 AgentCore를 연결했다.

## 사용 방법

- **탐색:** 검색 실행·지우기, 최근 검색과 현재 결과의 후보 선택을 제공한다.
  위·아래 화살표, Enter, Escape로 후보를 선택하거나 닫는다.
  이름 검색은 카카오 정확도순, 주변 검색과 검색어 없는 분류 탐색은 거리순이다.
- **저장:** 즐겨찾기·최근 본 장소·최근 검색을 다시 연다. 즐겨찾기 검색·분류와
  최대 5곳의 고정을 제공한다. 최근 검색은 12개, 최근 본 장소는 20개, 보관은 최대 30일이다.
- **길찾기:** 출발·도착을 이름이나 저장 장소로 지정한다. 도착부터 선택하면 출발이
  정해질 때까지 임시 상태로 둔다. 경유지·체류시간·출처를 유지하며 전체 순서를 뒤집을 수 있다.
- **지도:** 이동 후 `이 지역에서 검색`을 누르면 해당 범위의 결과를 새로 조회한다.
  `내 위치`는 누를 때만 권한을 요청한다. 우클릭·터치 길게 누르기·Shift+F10으로
  선택 지점의 출발·도착·주변 탐색·좌표 복사를 실행한다.
- **상세:** 목록의 포인터·키보드 초점을 지도에서 강조하고 주소 복사·장소 공유를 제공한다.
  공유된 카카오 이름·좌표는 조회용 힌트다. 같은 ID를 확인한 뒤 실제 상세를 표시한다.

지도 이동 중 결과를 자동 교체하지 않는다. 페이지 이동도 처음 검색한 범위를 유지한다.
이전 검색이나 위치 응답이 늦게 도착해도 더 최근의 지도 이동을 완료 처리하지 않는다.
일반 드래그·회전·핀치·거리 재기와 모바일 목록 공간, 사이드바 접기, AI 대화 상태를 유지한다.

최근 기록은 즐겨찾기·코스와 별도 저장한다. 기록 삭제는 이름이 표시된 영역에만 적용한다.
카카오 선택 토큰·대화 인증 정보는 저장하지 않는다. 저장 실패를 표시하고, 다른 탭에서
완료한 삭제가 오래된 임시 편집으로 되살아나지 않도록 삭제 세대와 기록별 변경 식별자를 사용한다.
삭제된 검색어를 별도의 메타데이터에 남기지 않는다.

## AI 답변 검증

서로 다른 브라우저에서 아래 원문 질문을 동시에 실행했다. 두 요청 모두 HTTP 200,
오류 없는 `done`까지 완료했다. 이는 관측 사례이며 항상 같은 지연·장소를 보장하지 않는다.

| 질문 | 실제 확인 결과 |
| --- | --- |
| 성산일출봉 근처 맛집을 알려주세요. | 성산어촌계해녀의집·코코마마 성산점·수마포식당, 카카오 ID·출처가 있는 추천 3곳 |
| 아이와 함께 방문할 장소를 추천하고 편의 정보가 확인되는지 알려 주세요. | 김녕미로공원·제주항공우주박물관, TourAPI의 주차 가능 안내와 2026-09-10 조회 날짜 |
| 성산일출봉 근처 맛집 한 곳과 확인된 주소, 출처를 간단히 알려 주세요. | 성산어촌계해녀의집, 서귀포시 성산읍 일출로 284-34, Kakao Local 출처·조회일 |

첫 두 응답은 약 14.2초·13.5초, 별도 주소·출처 요청은 약 14.1초였다.
실제 모델 호출은 총 3회다. 원문 성산 질문의 짧은 지도 요약에 주소·출처 문구까지
요구한 최초 검사 조건은 실패했다. 추천과 출처를 가진 지도 항목은 정상 반환됐으며,
주소·출처를 명시한 별도 질문으로 해당 내용을 확인했다.

성산 기준점은 동일 명칭·분류·상세 정보와 200m 이내의 중복 관계를 확인한 경우에만
기존 대표 ID `poi_0008`을 사용한다. 다른 동명 장소를 일반적으로 합치지 않는다.
아이 동반 질문에는 확인된 공공 상세의 항목별 근거를 전달한다.
샘플 기본 정보와 가족 태그, 확인되지 않은 화장실·접근성·휴무일을 검증된 사실로 바꾸지 않는다.
